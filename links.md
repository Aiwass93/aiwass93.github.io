## Useful

GreasyFork: [greasyfork.org](https://greasyfork.org/en)
Best site to find userscripts. useful for anyone that has a browser on computer. Sleazy Fork (sleazyfork.org) for userscripts for adult sites.

SauceNAO: [saucenao.com](https://saucenao.com/)
Best site to search the source of an image. very useful if the image is from Pixiv or any booru sites. If there's no results you can click the small buttons under the image (from google lens to yandex) to search it by other services.

## File sharing

Internet Archive: [archive.org](https://archive.org/)
Probably one of the best sites on the internet, free download of music, movies, books, games... not comprehensive but still a lot. (use <a href="https://github.com/elementdavv/internet_archive_downloader">THIS</a> to download lendable books!!)

RuTracker: [rutracker.org](https://rutracker.org/forum/index.php)
Best general purpose torrent site, you can find music, movies, games and more good stuff here. What I like most about this site is: administrators will verify if the source of the file is reliable. if you see "√ проверено", you can download it without any worry about file's quality!

Nyaa: [nyaa.si](https://nyaa.si/)
The RuTracker of ACGN related stuff and more (I downloaded Araki's photography work Tokyo Lucky Hole here where I cannot find it anywhere else on the internet).

Nicotine+: [nicotine-plus.org](https://nicotine-plus.org/)
A <a href="https://www.slsknet.org/news/node/1">Soulseek</a> client, works better on Linux and has more features. If you cannot find an album here, you probably won't be able to find it anywhere else on the internet.

Z-library: [z-library.website](https://z-library.website/)
One of the best site for reading and downloading books. note that its domain changes often and there's also lots of scam sites. verify the link before download files.

Anna’s Archive: [annas-archive.gl](https://annas-archive.gl/)
One of the best site for downloading books. note that its domain also changes very often.
